# Hojas demo (modo sin internet)

Cuando una hoja demo ya se diagnosticó bien con Grok, su resultado queda en `apps/api/storage/diag_cache/<hash>.json`.
Copia ese archivo aquí y haz commit: en la demo, esa misma foto se diagnostica al instante y sin internet.
Guarda también la foto original en `../demo_sheets/` (con el nombre del alumno) para tenerla a mano en el pitch.
